4. Fluxo: Recebimento e Resposta do WhatsApp

            sequenceDiagram
                participant Ws as @whiskeysockets/baileys
                participant Bayle as bayle.ts
                participant UC as ProcessingIncomingMessage
                participant WsAdapter as BaileysApiAdapter
                participant GptAdapter as ChatApiAdapter (Groq)
                
                Ws->>Bayle: ev.emit("messages.upsert")
                Bayle->>UC: execute(msg)
                UC->>WsAdapter: handleIncoming(payload)
                WsAdapter-->>UC: { to: remetente, text: "Oi" }
                Note over WsAdapter: Descarta se for "fromMe"
                UC->>GptAdapter: reply("Oi")
                GptAdapter-->>UC: "Olá! Tudo bem?"
                UC->>WsAdapter: send({ to: remetente, text: "Olá! Tudo bem?" })
                WsAdapter->>Ws: sendMessage()
                UC-->>Bayle: null

5. Fluxo: Registro de Usuário

            sequenceDiagram
                participant Client as Web/Mobile Client
                participant Ctrl as UserController
                participant UC as RegisterUserCase
                participant Repo as UserRepository
                participant JWT as TokenJWT
                
                Client->>Ctrl: POST /api/register
                Ctrl->>UC: execute(user)
                UC->>Repo: findByEmail(email)
                Repo-->>UC: undefined
                Note over UC: Executa bcrypt.hash(password) & Gera UUID v4
                UC->>Repo: save(new_user)
                Repo-->>UC: void
                UC->>JWT: encode({ id: new_user.id })
                JWT-->>UC: "jwt_token_string"
                UC-->>Ctrl: token
                Ctrl-->>Client: 200 OK { token }

6. Fluxo: Login de Usuário

            sequenceDiagram
                participant Client as Web/Mobile Client
                participant Ctrl as UserController
                participant UC as LoginUserCase
                participant Repo as UserRepository
                participant JWT as TokenJWT
                
                Client->>Ctrl: POST /api/login {email, password}
                Ctrl->>UC: execute(user)
                UC->>Repo: findByEmail(email)
                Repo-->>UC: user_owner (Db)
                Note over UC: Valida se usuário existe e
compara bcrypt.compare(password)
                UC->>JWT: encode({ id: user_owner.id })
                JWT-->>UC: "jwt_token_string"
                UC-->>Ctrl: token
                Ctrl-->>Client: 200 OK { token }
